# Инструмент визуализации графа зависимостей

## Этап 1: Минимальный прототип с конфигурацией

Данный репозиторий содержит реализацию **Этапа 1** практической работы по дисциплине "Конфигурационное управление".

**Цель этапа:** создание минимального CLI-приложения на C++, которое считывает, валидирует и выводит настраиваемые пользователем параметры из конфигурационного файла формата JSON, а также демонстрирует корректную обработку ошибок.

> _Примечание: Логика получения зависимостей и визуализация будут реализованы в последующих этапах._

---

### Описание параметров конфигурации

Источником настроек является файл `config.json`. Поддерживаются следующие параметры (согласно Варианту №23):

| Параметр           |  Тип   | Описание                                                                                                 |
| :----------------- | :----: | :------------------------------------------------------------------------------------------------------- |
| `package_name`     | string | Имя анализируемого пакета (не может быть пустым).                                                        |
| `repository_url`   | string | URL-адрес репозитория (должен начинаться с http:// или https://) или путь к файлу тестового репозитория. |
| `test_mode`        |  bool  | Режим работы с тестовым репозиторием (`true` или `false`).                                               |
| `package_version`  | string | Версия анализируемого пакета (не может быть пустой).                                                     |
| `output_file`      | string | Имя сгенерированного файла с изображением графа (обязательно расширение `.png` или `.svg`).              |
| `ascii_tree`       |  bool  | Режим вывода зависимостей в формате ASCII-дерева (`true` или `false`).                                   |
| `filter_substring` | string | Подстрока для фильтрации пакетов (может быть пустой).                                                    |

---

### Сборка и запуск

Для сборки проекта требуется компилятор C++ с поддержкой стандарта C++17 (например, MinGW/g++).

**1. Сборка основного приложения:**

````bash
g++ -std=c++17 -Wall -Wextra -o app.exe src/main.cpp src/config.cpp
**2. Сборка и запуск модульных тестов:**
````bash
g++ -std=c++17 -Wall -Wextra -o test_app.exe tests/test_config.cpp src/config.cpp
.\test_app.exe
**3. Очистка артефактов сборки:**
````bash
del app.exe test_app.exe
````
